## 새 버전 올리는 방법
1. 이 폴더에 새 버전 파일 추가
2. `assets/main.js`의 이미지 프롬프트 메이커 카드에서 `version`, `date`, 두 버튼의 `url` 수정
3. 위 버전 이력 표에 한 줄 추가
