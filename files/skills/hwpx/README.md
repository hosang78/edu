# 한글(HWPX) 문서 작성 스킬

랜딩 페이지의 "한글(HWPX) 문서 스킬" 카드에서 내려받는 파일을 관리하는 폴더입니다.

## 버전 이력
| 버전 | 등록일 | 파일 |
|------|--------|------|
| ver1 | 26.10.10 | suhyup_hwp_skill_ver1.zip (교체됨, git 이력에 보관) |
| ver2 | 26.10.21 | suhyup_hwp_skill_ver2.zip |

## 새 버전 올리는 방법 (예: ver2)
1. 이 폴더에 `suhyup_hwp_skill_ver2.zip` 추가
2. `assets/main.js`의 hwpx 카드에서 `version`, `date`, `url` 3곳 수정
3. 위 버전 이력 표에 한 줄 추가 (이전 버전 파일은 보관용으로 두거나 삭제)
