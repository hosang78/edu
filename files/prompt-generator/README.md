# 수협 프롬프트 생성기

랜딩 페이지의 "수협 프롬프트 생성기" 카드에서 내려받는 파일을 관리하는 폴더입니다.

## 버전 이력
| 버전 | 등록일 | 생성기 | 도움말 |
|------|--------|--------|--------|
| v3.09 | 26.10.11 | suhyup-prompt-generator_v3.09.html | suhyup-prompt-generator_v3.09_manual.html |

## 새 버전 올리는 방법
1. 이 폴더에 새 버전 파일 2개 추가
2. `assets/main.js`의 프롬프트 생성기 카드에서 `version`, `date`, 두 버튼의 `url` 수정
3. 위 버전 이력 표에 한 줄 추가
